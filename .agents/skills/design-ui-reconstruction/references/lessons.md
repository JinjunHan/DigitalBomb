# 从已有对话归纳的还原经验

以下是本项目案例与最终接受的做法，不要求以后每个页面照搬相同坐标、尺寸或控件数量。路径相对仓库根目录；历史文档可能保留被后续纠正的方案，当前用户指令和代码优先。

## 1. 首页：先切完整按钮，避免用代码重画美术

早期把按钮底板、系统文字、图标拼装，功能可用但外观不够接近。用户明确修正：在线匹配与好友对战要整块切下，包含背景、图标、文字；设置和声音也是完整控件；怎么玩左侧的问号不能漏掉；头像框、昵称背景框也需要独立素材。

因此固定品牌标题和固定按钮文案可以烘焙，昵称与机器数字必须动态。不要把“文字应该全部原生化”当作通用规则；需要多语言或动态按钮名称时再分离并恢复正确字体。用户改了名字时，先确认当前品牌图，不要混用旧标题。

可参考：
- `scripts/slice-lobby-controls.py`：完整控件裁切、透明孔洞；只作为已有稿的复现脚本。
- `docs/design/lobby-layers/control-slices.json`：来源图、矩形与轮廓。这里矩形为 `[left, top, right, bottom]`，不是 `[x, y, width, height]`。
- `assets/resources/art/lobby/`：完整控件名称含 `match-full`、`friend-full`、`help-full` 等。

新切图清单应明确坐标体系。记录裁切偏移和透明留白，否则视觉轮廓对齐了，点击区域或动画锚点仍可能偏移。

## 2. 个人资料：纸张和控件各自独立

`docs/design/02-profile.png` 包含纸张底板、返回、标题、头像区、昵称框、微信入口、取消和保存。纸张被控件遮挡的部分需要补全，不能直接把整张设计图作为底图，再在上面叠第二套控件。

微信导入按钮曾因直线多边形蒙版切穿圆角和倒角，出现背景异常。处理重点是贴合真实曲线轮廓并保留阴影，不是更换按钮颜色。参考 `scripts/slice-profile.py` 中该按钮的曲线轮廓；旧坐标仅适用原稿。

头像分四类：纸纹/罗盘背景、实际头像、中空边框、独立选中徽章。选中图标不能跟着示例头像一起切进普通状态。源图被遮挡而无法恢复的框和底纹可以参考设计图生成，记录在 `docs/design/profile-avatar-assets/`；生成结果不能称为原稿无损切图。

## 3. 输入框：既要对齐，也要保护原生编辑生命周期

昵称位置错误与键盘弹出后立刻消失是两个问题，不能只改坐标：

- 本项目 Cocos 3.8.8 EditBox 采用单行模式，文字节点使用与内部定位匹配的左上锚点 `(0, 1)`，垂直居中并固定尺寸。Label 默认自动尺寸可能覆盖预期高度；当前实现用 `Label.Overflow.CLAMP`，为左内边距和右铅笔留空间。
- 检查文字可见边界、整框点击区域、实际原生输入覆盖范围。不要无条件把上述锚点方案移植到其他 UI 框架。
- 微信原生键盘可能在 `editing-did-began` 之前同步触发尺寸变化；本项目在触摸开始就标记输入会话，编辑期间延后被动 resize/render，防止销毁焦点节点。
- 输入结束后合并待处理刷新；若用户已开始下一次编辑，继续延后。保存、返回、取消、切换头像先同步草稿并结束编辑，取消不保存。

参考 `assets/scripts/shared/input-edit-session.ts`、`tests/input-edit-session.test.ts`、`GameApp.ts` 的昵称编辑代码。该原因来自代码排查；浏览器焦点验证不能替代微信真机软键盘验证。

## 4. 游戏记录：还原外观时也要容纳真实数据

设计图只有三条记录不代表运行时只能展示三条。用户反馈记录多时翻页难用，当前改为原生 ScrollView + Mask：常驻四行、展开八行，连续滚动；我的/对手可切换，展示数量并提供回到最新。

通用经验是保留滚动位置：在底部才跟随新记录，查看旧记录时不强制跳底；输入数字、异步重绘和切换标签不清空浏览位置，新房间才重置。展开查看不能遮掉回合倒计时信息。四/八行是本次布局选择，不是技能的固定指标。

参考 `docs/design/guess-records.md` 与 `GameApp.ts` 的 `recordList`、`recordTabs`。只在任务涉及记录列表时应用，不为普通切图工作主动重做信息架构。

## 范围内的验证样例

- “按设计图做两个主按钮”：应先产出包含背景、图标、文字的切图；不能只交付两个 Graphics 矩形。
- “做可编辑的个人资料”：图上示例昵称不应出现在运行素材中；点击、输入、取消/保存应使用真实状态。
- “按钮背景不对劲”：先检查 PNG alpha、曲线轮廓、边缘残留和重复叠图，定位后只修相关素材。
- “改一个网络错误提示”：无需重新切图，也不需要读取场景动画流程。
