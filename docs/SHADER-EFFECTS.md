# 局部 Shader 特效

本次保留全部现有美术布局，在 Sprite 上叠加单 pass 材质。客户端使用 Cocos Creator 3.8.8，微信小游戏为交付目标。

| 位置 | 触发与行为 |
| --- | --- |
| 准备/对战计时牌 | 仅自己需要操作的最后 5 秒泛红脉冲；锁定密码、对手回合、开局等待、过期和结算时关闭 |
| 猜测结果底图 | 命中时一次金色扫光，零命中/超时短促红闪；提交等待时不闪 |
| 弹窗/个人资料纸张 | 复用现有转场时钟，用噪声边缘显现/消散；原有文字和交互保持独立 |
| 书房和桌面 | 低强度缓慢暖光；前景道具及原有视差不变 |
| 美术按钮/房间码 | 按下时亮边，取消或松开后消失；房间码输入到四位时纸面和加入按钮扫光 |

## 实现与调节

- `assets/resources/effects/ui-feedback.effect`：沿用引擎内置 Sprite 顶点/混合管线，每像素一次纹理采样。噪声仅在纸张显隐时计算，无额外纹理或全屏后处理。
- `assets/scripts/SpriteEffects.ts`：`attach(sprite)` 后可调用 `reveal(0..1)`、`ambient(strength)`、`pulse(0..1)`、`sweep()`、`flash()`、`press(boolean)`。扫光 0.65 秒，红闪 0.32 秒，环境强度上限 0.12。
- `SceneBackdrop` 的房间/桌面强度分别为 0.035/0.06。持续光效使用游戏全局时钟，输入重绘不会重启计时脉冲。
- `shared/shader-feedback.ts` 决定倒计时是否需要提醒；边界由 `tests/shader-feedback.test.ts` 覆盖。

关闭设置中的「动态效果」会恢复原材质，重新打开不会补播短暂扫光/红闪。空闲 Sprite 恢复原材质，节点销毁时释放私有材质；资源加载失败时保留原图。受影响 SpriteFrame 禁用动态打图集，并按实际 UV 基向量计算局部坐标，以兼容已打包、旋转或裁切的帧。

## 包体

新增 Shader 后对 `assets/resources/art/scene/table.png` 仅做 PNG IDAT 的 Zopfli 无损重压缩（15 次迭代），其余 PNG 数据块、尺寸和 `.meta` 保留。文件从 1,354,436 字节降到 1,301,938 字节，节省 52,498 字节。解码后的 RGBA 逐字节一致，尺寸为 864×1536，RGBA SHA-256 为 `db280c0aabb0e5c5ac9a21c5c4d2554eafc3797942431f01958ba6701f0c7ea3`。项目 28 MiB 包体预算保持不变。
