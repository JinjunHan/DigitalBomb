# 首页数字洗牌与静态沙漏

- 数字：从现有口令键盘 key-0…key-9 提取原字形，生成 640×80 透明图集；未新增字体或用文字近似绘制。来源和图层说明见 `docs/design/lobby-shuffle/manifest.json`；深浅底图用于检查轮廓。原有资源 UUID 未变。
- 首页：资源就绪且首页可见后立即播放首次滚动；四位错峰减速，每位停止间隔 0.24 秒（0.90、1.14、1.38、1.62 秒），停止时轻微回弹 0.18 秒并触发一次 tap 音效；随后完整停留 5 秒再循环。进入新一轮随机数可重复。状态独立于 UI 节点，重绘不重置；离开页面停止计时，返回立即重新播放。关闭动效时静态显示。
- 沙漏：固定使用已有图集的正立首帧，移除运行时帧切换。
- 真实浏览器验证：首次动画、每位一次落定音效触发、稳定保持至下一周期前、下一循环、重绘保持、返回首页立即播放、沙漏静止、动效关闭、390×600 短屏。使用独立本地测试对局数据，无真实微信登录。
- `shuffle.gif` 来自连续运行截图；为便于预览，GIF 末尾停留缩短为 1.5 秒，游戏实际停留 5 秒。
- `npm test` 53 项通过；服务端及客户端类型检查通过；Web 与微信构建通过。微信总包 27442.1 KB，导出 `build/wechatgame/`。尚未执行微信真机测试或正式发布。

音效沿用现有解锁/静音/后台策略：首次未触摸解锁时无声，视觉照常播放；覆盖弹窗时不触发首页落定音效。
