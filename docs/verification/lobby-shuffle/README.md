# 首页数字洗牌与静态沙漏

- 数字：从现有口令键盘 key-0…key-9 提取原字形，生成 640×80 透明图集；未新增字体或用文字近似绘制。来源和图层说明见 `docs/design/lobby-shuffle/manifest.json`；深浅底图用于检查轮廓。原有资源 UUID 未变。
- 首页：资源就绪且首页可见后立即播放首次滚动；四位错峰减速，最后一位在 1.25 秒落定；随后完整停留 5 秒再循环。进入新一轮随机数可重复。状态独立于 UI 节点，重绘不重置；离开页面停止计时，返回立即重新播放。关闭动效时静态显示。
- 沙漏：固定使用已有图集的正立首帧，移除运行时帧切换。
- 真实浏览器验证：首次动画、四秒以上稳定保持、下一循环、重绘保持、返回首页立即播放、沙漏静止、动效关闭、390×600 短屏。使用独立本地测试对局数据，无真实微信登录。
- `shuffle.gif` 来自连续运行截图；为便于预览，GIF 末尾停留缩短为 1.5 秒，游戏实际停留 5 秒。
