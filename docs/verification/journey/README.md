## 已修复

1. 请求发出后立即重绘忙碌/禁用状态，匹配、建房、入房等操作不再等回复才更新按钮状态；重复提交仍由 busy 拦截。
2. 普通提示可点击关闭。到期仅移除提示节点，不再重绘整页，避免打断资料编辑、原生授权按钮和界面动效。
3. 切换主页面、房间或阶段后清理上一页的旧提示；当前页面新产生的错误继续保留。
4. 分享邀请入房失败，将四位口令正确填回口令输入框，而非局内猜测草稿。
5. 新房间/再战重置临近超时的提醒标记，避免同一 turn 编号导致下一局漏提醒。
6. 补猜倒计时改为“最后补猜 / 等待对手补猜 + 秒数”，减少狭窄状态牌的文字拥挤。
