# 2026-10-31 页面交互优化

审查范围为选档、教学、练习和推理笔记。继续复用现有独立美术控件；没有生成新图片、改变匹配规则或修改线上服务。

## 已改善

- 选档确认文案随选择变化，明确显示已选的位数与模式，确认后才记忆；取消保留旧偏好。
- 练习和教学选中数字卡后，删除该位而不是误删末位，后面的数字前移；未选中时保持删除末位。满位后继续输入会明确提示点击卡牌修改，不再无反馈。
- 练习输入区显示已输入数量或当前正在编辑的位数，选中卡牌上移且变色。
- 原生文字放入按钮或卡牌节点，按压时与美术底板一起缩放。
- 历史翻页同步选择新页第一条记录；手动设置的对照记录继续保留。增加回到最新按钮，同时定位末页并选择最新记录。
- 单页历史隐藏无意义的翻页控件；空数据与没有可比记录时，说明位于详情面板中央。
- 复制操作显示选中的记录编号；超时、未到自己回合或练习已破解时解释不可复制的原因。原有回合/期限校验保留。
