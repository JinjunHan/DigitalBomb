固定按钮保留原稿图标、雕刻文字和底板；数字、命中数、计时、候选数、选择态使用实际运行值。部分底纸及空白卡槽由 imagegen 补全，非无损裁切。运行资源经过压缩，原始设计及补全图完整保留。
