# 回合牌居中与数字滚动

沿用 battle/round.png 木牌，不新增或近似绘制美术资源。将“第”、动态轮数、“轮 / 20”和返回箭头独立定位；动态轮数位于固定 50 × 42 的裁剪区域，单、双位数字保持居中。

轮数连续增加时，旧数字向上退出，新数字从下方进入，持续 0.4 秒。动画状态独立于界面节点重建，同轮同步或输入刷新不会重播。首次进入、新房间、重连、跳轮和关闭动效时直接显示当前值。

验证：42 项测试通过；服务端和客户端类型检查通过。运行 scripts/verify-round-roll.cjs 验证 1、9、10、20 轮，9→10 动画期间重绘，动画结束位置，回合牌菜单点击及短屏布局。round-9.png、round-10.png、round-short.png 为 Web 实际运行截图；round-roll.gif 为实际连续采样帧的局部放大，播放节奏仅用于展示。
