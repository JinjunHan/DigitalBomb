引擎已正式确定为 Cocos Creator 3.8.8。日期：2026-10-26。

## 已实现

- Cocos 原生 Canvas/Graphics/Label/EditBox 界面，独立生成的背景素材，可交互数字牌与数字键盘；不是把整张概念图当界面。
- 首页、个人资料、匹配、口令加入、等待房间、准备、局内猜测、结算、设置与玩法弹层。
- 右上角不放自定义按钮，首页设置在左下，微信适配层提供胶囊避让计算；真机仍待验证。
- 本地开发身份，系统头像/昵称兜底，手动修改昵称及预设头像，SQLite 保存。
- 四位口令（保留前导零）、两席原子加入、活动口令保留、关闭冷却、房间过期、加入限流。
- 真人队列优先、每次固定 3～8 秒随机 AI 兜底；300 个组合昵称和 8 个预设字形头像，AI 后台单独身份，不使用真实用户资料。
- AI 不读取玩家谜底，依据自己猜测获得的反馈过滤 10,000 个候选，3～8 秒随机思考。
- 锁定四位底牌，位置命中反馈，准备/行动超时，后手补猜、同轮平局、20 轮上限、认输。
- 最近三次记录和完整记录分页。完整记录仍保留键盘、草稿、倒计时；当前采用分页按钮，尚未做滑动列表。
- WebSocket 权威状态、请求 ID 幂等、轮次校验、公开快照、自动重连、双端登录接管、再战换先手。
- 用户和结算摘要 SQLite 持久化，房间运行态目前在内存。短时断线可恢复；进程重启不恢复进行中房间，不计失败。
- 构建脚本、类型检查、规则/服务/实际网络集成测试。

3. 已配置 AppID wx3f231fcad8d0170f 和域名 bomb.aiforevery.cn，已实现 wx.login → code 换会话与 OpenID 绑定。尚缺服务器 AppSecret，因此微信真实登录尚未验收。头像昵称授权仍未实现。
4. HTTPS/WSS 已在公网验证；微信发布仍需合法域名、隐私能力声明、资料审核、包体优化及真机适配。
5. 缺少持久化对局恢复、多实例匹配、监控指标、运营开关、完整在线匹配冷却策略和压测。终态房间内存保留 10 分钟供复盘，尚未实现 PRD 的 7 天详细复盘保存。
6. 公网以 DEPLOYMENT_MODE=preview 运行，浏览器允许创建体验账号，有登录频率和总账号数限制。微信 code 路径缺少 AppSecret 时返回 503，不降级游客。服务器默认仅监听 127.0.0.1；NODE_ENV=production 仍拒绝启动。
7. 隐私政策、用户协议、平台资料审核与正式发布材料需接入真实产品主体；开发版没有伪造正式协议或资质。
