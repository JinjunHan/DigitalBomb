## 对手反馈的情绪层次

只展示对手本次命中数量，不展示正确位置，也不把每次命中数理解为永久解锁进度。猜测结果可能升降；命中 3 位不代表下一次必然破解。

| 命中 | 建议反馈 | 动画及声音方向 |
| --- | --- | --- |
| 0 | 一位也没中，暂时守住了 | 对手区小纸牌轻晃，轻松的短木音 |
| 1 | 对手找到了一点线索 | 小幅亮起黄铜边缘，一声清脆轻响 |
| 2 | 对手命中两位，保持专注 | 琥珀边缘短亮，双音提示 |
| 3 | 只差一位！轮到你反击 | 酒红细边短脉冲，较低的紧张双音；不全屏闪红、不持续心跳 |
| 4，仍可补猜 | 你还有本轮补猜机会 | 明确强调补猜与真实服务器倒计时，不提前显示失败 |
| 4，已结束 | 本局结束 | 直接衔接实际结果，避免叠加多层终局提示 |

“轮到你反击”只在状态确认为本人行动时使用；若轮数上限已结束，使用终局结果。文案表达局势，不使用侮辱或虚假激将语。

## 接入时序建议（尚未实现）

- 对手反馈放在对手头像/手牌附近，自己反馈放在中部偏上。键盘与输入卡牌保持可点，普通反馈不要求确认。
- 默认约 0.18 秒入场、1.2～1.6 秒展示、0.18 秒退出；3 位可以展示约 1.8 秒。计时不暂停，不增加输入等待。
- 新反馈基于房间 ID、turn、playerId 去重；重连快照不重播全部历史，也不按分数变化判断是否为新猜测。
- 终局优先于一般命中和回合提示；可补猜时合并“对手 4 位命中”与“最后一次补猜”，避免连续遮挡。单次超时使用非阻断条幅，连续超时才出现胜负结束状态。
- 游戏音效关闭则静音，界面动效关闭则静态短提示；振动服从开关，只在必要的紧张/补猜状态触发一次。
- 请求确认超时表示结果未知，不能显示提交失败或自动重复猜测；同步服务器状态后再展示确定结果。
- 取消状态不揭示底牌；真正结束才按已有协议展示已公开的双方底牌。断线判负复用胜负模板并替换原因，不复用“正在重连”的持续加载态。
- 所有开关、数字、时间、结果原因与记录行均由运行时填充。生成图中的示例数字只用于构图，不作为规则或测试数据。
- 素材加载失败的实际回退必须用不依赖这些素材的基本控件实现；图稿仅提供正常视觉基准。

## 后续素材拆分

统一拆为纸张框体、标题/状态徽章、完整固定按钮、图标、独立光效与动态文字区。背景复用现有场景，不把生成图中的背景一并导入游戏。保持右上角微信安全区，不新增该区域的关闭按钮。

局内效果图 03 专门说明对手反馈的位置和情绪，省略了部分常驻控件；接入时仍保留现有猜测记录、确认猜测按钮和菜单入口，不用它替换整个游戏页。组图的列数可能与提示词不同，但所有要求的状态均已保留。
