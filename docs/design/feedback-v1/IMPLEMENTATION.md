# 新状态设计接入

已将本目录图稿拆为 44 张透明 PNG，并接入 Cocos 客户端。原图与提示词保留；运行资源位于 `assets/resources/art/feedback/`，包含对应 `.meta`。

## 素材及复现

- `implementation-slices.json`：源图、LTRB 源像素矩形、蒙版、动态区域修补、用途和绘制顺序。
- `scripts/slice-feedback.py`：只生成本批资源和 `shared/feedback-art.ts`。依赖 Pillow、imagequant。运行 `python scripts/slice-feedback.py` 可复现，已存在的 UUID 不变。
- 静态状态文案及完整固定按钮保留美术；命中数、结果原因、双方底牌、猜测次数、通用错误文本由运行时填入。
- 示范数字和旧按钮区域使用现有 `art/modals/record-row.png` 的干净纸纹修补，做色调匹配和边缘融合。蒙版采用超采样轮廓。部分面板轮廓、纸纹和结算布局作了适配，**并非逐像素无损切图**。
- 输出缩至最长边 850 像素以内，使用 alpha 感知调色板压缩。深浅底检查图为 `dark-slices.jpg`、`light-slices.jpg`。整张原稿不会作为运行界面导入。
- 上方对手横条中的剪影是固定的通用人物图标；真实对手头像仍显示在原游戏页面，不把图稿示例人物当玩家头像。

## 状态与交互

- 自己的猜测：验证中、命中 0～3 位、4 位等待对手补猜；只展示总命中数。
- 对手猜测：0 位轻晃、1～2 位线索提醒、3 位酒红压力提示、4 位补猜提示。横条不拦截输入。当前结果已结束时，直接展示终局反馈，避免再播放过期行动提示。
- 原有音效按状态复用，紧张反馈用 warning 音；音效和振动服从设置。未新增音频文件。
- 初次进入、新房间和重连同步不重播历史。重复相同快照不会重复反馈。进入取消状态会清除旧反馈。
- 普通超时只是短提示；连续超时与补猜超时进入各自终局反馈。网络确认超时使用独立同步提示，不自动重新提交。
- 准备超时、房间过期、玩家离开、双方掉线使用中性取消面板，不显示对手底牌。
- 真正结束后展示胜利/失败/平局与正确归属的原因、真实猜测次数、已公开底牌。再战等待和已离开/过期有独立状态；其他网络错误仍显示轻提示，不伪装成邀请过期。
- 原有记录弹窗继续支持滚动和双方切换；补入空态插画，超时行沿用动态破折号与文字。
- 初次连接及失败接入新面板。素材不可用时保留原生可操作回退，不依赖加载失败的图片。

## 范围与验证

没有修改服务端胜负、回合、超时或匹配规则。浏览器状态夹具用于覆盖少见状态与真实鼠标点按；不在客户端添加测试入口。详细结果见 `../../verification/feedback.md`。
