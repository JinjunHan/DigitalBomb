# 第二轮细化清单

坐标延续 941×1672、LTRB。层级为共用场景 → 托盘 → 面板/手牌 → 手部 → 标签/键盘。

| 素材 | 来源/处理 | 用途 |
|---|---|---|
| tray | 04 原稿被按钮遮挡的托盘，imagegen 参考补全，透明背景；保存原始结果及提示词 | 准备页和对局页键盘底板，独立于每个按钮 |
| card-paper | 04 中央手牌被数字遮挡的空白纸张，imagegen 参考补全；无数字或发光 | 普通手牌底板 |
| card-selected | 04 选中牌透视校正后只保留原金边、中央透明 | 独立选中覆盖层，不烘焙到普通卡牌 |
| play-hand-left/right | 05-gameplay-v2 手部轮廓透明裁切 | 对局手牌手部，在头像及标签下方 |
| keypad masks | 原始键帽 RGB 不变，按倾斜边缘细化透明轮廓 | 去除矩形裁切残留的底色 |
| profile portrait frame | 复用已验证的透明头像框与背景 | 所有头像编号均有回退，昵称截断后保持可读 |

字体：动态数字使用项目已有的 FriendDigits（Libre Baskerville Bold 子集），以接近原稿衬线数字的笔画重量。长昵称在窄牌上截断，点按对手名牌显示完整姓名。

匹配页复查追加：沙漏帧只清理主体外的极淡矩形 alpha；底座的旧矩形纹理补片另用 imagegen 参考补全，原图与提示词位于 `../matching/base-reconstruction/`。匹配和对局头像均使用原生椭圆 Mask 限定圆形范围，纸色头像上的回退字改用深色。
