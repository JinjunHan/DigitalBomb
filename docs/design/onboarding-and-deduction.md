# 新手教学与推理辅助

## 本次交付

- 新用户首次到大厅展示可跳过的练习室；通过「怎么玩」随时重进。
- 互动教学要求实际输入 `1234`、只改第一位输入 `9234`，再回答单位置推理与零命中的含义。错误操作说明原因，不推进步骤；完成标记与首次展示标记分别保存在本地。
- 2 位 / 3 位 / 4 位独立练习：每位均为 0～9，允许重复和前导零，无倒计时、不上传战绩。每次开始固定谜底；重复猜测提示修改，破解后可复盘、重练或升级位数。
- 正式匹配和好友对战保持四位，避免拆分匹配池。服务端新局默认 30 大轮、每次行动 60 秒；准备和重连时限不变。上限轮双方仍有相同机会，保留先手破解后的后手补猜。
- 对局中「推理提示 / 排除」展示自己的线索；原有双方全部记录仍可访问。最近记录可点击复制；提示页可以分页、选择对照记录并复制后修改。
- 新规则页采用动态文字，替代包含旧 20 轮 / 30 秒文字的静态说明图。快照增加 `roundLimit` / `turnMs`，标题、说明和上限结算使用本局参数。

## 提示的逻辑边界

计算输入仅有玩家自己的已提交猜测和对应命中数。枚举与全部反馈一致的候选组合，取各位置数字的并集为「可能」，其补集为「排除」。一个位置只剩一个候选才显示「已确定」。不会读取 `ownSecret`、`revealed`、对手历史或本地练习谜底。

- `1234 → 0` 只排除第一位 1、第二位 2、第三位 3、第四位 4，不全局排除这些数字。
- 只改一位，命中加 1：新数字正确；减 1：旧数字正确；不变：该位新旧数字均不正确。
- 修改多位时，不根据总数变化断言具体位置；全部命中时则确认所有位置。
- 超时记录没有反馈，不参与候选约束；重复记录不增加信息。
- 不一致或非法反馈显示同步提示，不能把全部数字标为排除。
- 「每位可能」不表示这些数字能任意组合，界面明确说明组合之间仍有约束。
- 打开提示不暂停服务器计时，面板显示持续更新的剩余秒数。复制时再次检查回合、阶段、连接、截止时间，过期不写草稿；结算或换房关闭面板。
- 结果按位数和有效历史缓存，输入数字和界面重绘不重复穷举。

## 多档位决策

本次将多档位用于无压力练习，正式队列保持单一四位规则。2/3/4 位的空间分别是 100/1,000/10,000 种，操作和反馈含义一致。未来若开放不同位数的真人房，应同时扩展服务端校验、机器人、快照、房间规则和对局美术，不能只减少客户端输入框。

增加轮数和时限提供思考空间，但并不保证缩短对局：30 大轮、双方各 60 秒，猜测阶段理论上限约 60 分钟。后续应观察有效猜测次数、超时、退出、自然破解和再玩率，再决定是否推出更短的正式模式。本次不修改机器人策略。

## 素材与构建

复用已存在的 `art/profile/paper`（空白纸张）、`art/modals/tab-off`（空白按钮底板）、`art/battle/card-paper`（数字卡牌）；实时标题、规则、候选和数字均为 Cocos Label。新增面板统一以 750×900 设计坐标按安全区域等比缩放，纸张保持原始宽高比；未新增位图包体。

Cocos 构建采用 loose spread 转换，新算法使用 `Array.from(string/Set)`，不能改回字符串或 Set 的展开语法。Node 类型检查和单测不足以发现此转换差异，需用构建后的客户端验证命中数和候选列表。

## 验证与发布边界

- 自动化覆盖逐位排除、组合一致性、前导零、重复数字、超时、无解数据、单位置对比、教学错误分支、练习通关、30 轮边界及最后补猜。
- Web 实际点击检查教学、2/3/4 位练习、复制修改、短屏、正式规则；双客户端本地对局检查 60 秒、30 轮、2916 候选、提示倒计时、复制和结算自动关闭。
- 微信导出目录为 `build/wechatgame/`，不提交构建文件。Web 是辅助验证，尚需微信开发者工具和 Android / iOS 真机检查。
- 此任务不包含远端部署。60 秒 / 30 轮必须在更新服务端后才对线上新局生效；发布时应协调客户端与服务端版本，避免新旧客户端的辅助能力不一致。

自动化交互回归脚本：`scripts/smoke-learning.mjs`。先启动本地服务、构建并预览 Web；设置 `PLAYWRIGHT_MODULE` 为可用 Playwright 模块路径（或安装在脚本可解析位置），可用 `LEARNING_SMOKE_OUTPUT` 指定截图目录。测试使用独立的本地临时账号，不对远端执行。
