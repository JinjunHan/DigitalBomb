## 接入与验证

`GameApp.joinArtwork()` 统一设计坐标、等比缩放与安全区；键盘底板和每个按键独立，按钮按压不会带动整块底板。18 张图全部就绪后才替换旧版回退。输入沿用现有 `digit` 逻辑及原生 Cocos 触摸键盘，不创建 EditBox 或唤起系统软键盘，数字输入与素材刷新不会重启共用背景。

本地 Web（470×836）实测：空值禁用加入；输入 `0381` 保留前导零；第五位不进入；删除变为 `038` 并禁用加入；清空恢复四个空槽。另一位本地测试玩家创建房间后，本页输入真实口令并成功加入双人准备；关闭后的失效口令显示错误且不清掉输入。「自己创建房间」进入新版好友房，返回按钮回首页。375×600 短屏中底部清空、0、删除按键完整显示，点 0 可正常输入。

截图：`docs/verification/join-room-filled.png`、`join-room-empty.png`、`join-room-short.png`。

验证：`npm test` 24/24，`npm run typecheck`、`npm run typecheck:client` 通过；Web 构建及微信导出成功。`build/wechatgame/` 主包 1914.5 KB（主包检查通过），resources 分包 20324.4 KB。本轮未做微信开发者工具/真机触控与安全区核验，未正式发布。背景沿用共用场景；字形为随包字体，不声称是原设计的精确字体。

## 口令输入动效

输入时保留当前页面、键盘与数字节点，仅更新变化的槽位：180ms 上方落入（10 设计像素），85%→105%→100% 缩放，淡入及 220ms 暖金描边闪光。删除位以 130ms 上移 8px、缩小并淡出；清空从右到左错开 30ms，总计最多 220ms。四位填满后加入按钮恢复颜色，并以 200ms 轻微回弹提示。

口令状态立即更新，动画不阻塞连续点击；重输同一槽位会停止原节点、透明度和高光动画，因此退场回调不会清除新数字。切页、重绘、销毁时显式停止这些动画。关闭界面动效时直接显示最终值；测试结束已恢复动效开启。

本地 Web 实测：输入 1234→删除→输入 5→清空，真实连续截图录成 `docs/verification/join-input-motion.gif`（未放慢运行时间）；快速输入→删除重输→清空后马上输入 06，最终 06 正确且无残影；补齐四位后加入按钮可提交当前口令；动效关闭时输入/删除/清空直接完成，见 `join-motion-off.png`。本次仍未执行微信真机验证。

验证：24 项测试、服务端与客户端类型检查通过，Web 与微信构建成功；微信主包 1916.8 KB、resources 分包 20324.4 KB，主包检查通过，导出目录仍为 `build/wechatgame/`。
