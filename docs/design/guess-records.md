# 猜测记录滑动列表

游戏内取消分页与展开后挤占底牌区域的布局。常驻面板显示四行，可上下滑动浏览所有记录；我的/对手标签展示各自记录数。点击展开后显示八行大列表，仍展示当前行动方和倒计时。结算记录复用同一列表。

记录按轮次排列，最新一条用深金色标识，超时记录保留。初次打开定位最新；停留底部时自动跟随新增记录，向上浏览时保留偏移。输入数字、网络重绘、双方切换和关闭展开面板均保留对应列表位置。按钮可随时回到最新。新房间清空旧位置。

实现采用 Cocos 原生 ScrollView 和矩形 Mask，支持触摸拖动、惯性和鼠标滚轮，不依赖浏览器 DOM。四行/八行的高度随安全区布局适配。

验证：客户端类型检查、Web 构建和微信构建通过；使用独立本地测试服务提供双方各 18 条记录，浏览器验证滑动至早期记录、输入数字后保持位置、切换双方、回到最新和八行展开布局。截图：`../verification/records-scroll-compact.png`、`../verification/records-scroll-expanded.png`。微信真机触摸手感尚未验证。
