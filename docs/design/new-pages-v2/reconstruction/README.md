# 分层还原记录

来源为上级目录 7 张 imagegen 设计稿，运行实现位于 `assets/scripts/LearningPanel.ts`。正式匹配和好友房默认 4 位、分别记忆选择的规则保持不变，服务端没有改动。

## 素材与坐标

- [分层清单](manifest.json)：背景、固定控件、动态内容、状态层和点击层的绘制顺序。
- [切图清单](cuts.json)：每项来源、`[left, top, right, bottom]` 源像素矩形、圆角/椭圆蒙版、固定文字属性和输出路径。
- [背景补全提示词](generation.json)、[空白控件提示词](controls-generation.json)：内置 imagegen 的精确输入及生成原路径。生成原图已复制到本目录，运行时不依赖机器私有路径。
- [深浅背景检查图](contact-sheet.png)：独立按钮、卡片、标签的轮廓与透明度检查。

4 张背景和 1 张空白控件源图属于生成补全，不是逐像素无损切图。完整开始匹配、创建房间、开始教学、练习档位、键盘、提示、对照、复制、返回等按钮从原稿裁切，保留图标与固定文字。每个控件有独立节点和完整点击区域，不重复叠文字。

背景只保留静态纸面、场景和说明插画。练习室的 1234→9234 插画是固定教学插画；练习记录、教程答案、猜测数字、候选数、命中数、选中态和倒计时全部来自运行状态。教程第三步的大纸面保留空卡槽与装饰边框，数字独立绘制。

## 可复现流程

在项目根目录运行 `python3 scripts/slice-learning-v2.py`，依赖 Pillow 与 pngquant。脚本只写 `assets/resources/art/learning-v2/`，保留已有 UUID，并生成缺失的 `.meta`。不覆盖旧页面素材。

原图保持 941×1672。运行背景缩为 750×1333 JPEG quality 55；控件按源尺寸 80% 输出 PNG，使用 pngquant quality 40–65、关闭抖动压缩。透明轮廓使用 4 倍超采样蒙版；切图检查图在压缩后生成。此为明确的有损运行优化，原始生成 PNG 完整保留。空白控件使用九宫格，保护边框和圆角。

所有节点使用统一的 941×1672 设计坐标，交互范围 y=64…1570 适配安全区，按钮、文字和点击区一起缩放。场景边缘允许延展。固定背景没有入场动画；输入与记录更新不会重播动画，按下反馈只作用于独立按钮。

素材一次性加载完成后才展示新页面。失败时显示重试和返回，不混合半套新旧页面。记录默认打开最新一页，翻页后普通重绘保持位置；记录超过 3 条可翻页，最多 30 条的实际布局已验证。

## 与概念稿的动态适配

- 选择态使用独立绿色勾选，首次默认说明常驻，不把“上次选择三位”烘焙成真实玩家偏好。
- 教程支持所有步骤及错误重试；独立的 0 命中例子明确提示切换例子，避免与刚确认的第一位混淆。
- 逐位排除按实际位数生成 0–9 卡片，颜色与 ✓/× 同时表示状态；不读取对方密码。
- 记录对比只在确实改变一位时展示对应卡牌；多位变化与超时记录使用相应说明。
- 实战显示实时倒计时，练习不显示虚构的 45 秒；空记录、破解成功和复制不可用均有对应状态。

实际截图与验证范围见 [交付记录](../../../verification/learning-v2/README.md)。

## 主按钮轮廓修正

开始匹配、创建房间、开始教学已改用 [独立曲线轮廓](button-contours.json)，替代通用圆角矩形蒙版。坐标相对原始裁切矩形；短弧控制柄长度受相邻边约束，避免长直边插值过冲。轮廓内保留原稿 RGB，外部透明；原稿混有纸色的投影改为中性黑色 alpha 柔影（2 像素模糊、下移 2 像素、30% 强度）。原图与裁切矩形、运行尺寸、节点位置、点击区及 .meta UUID 不变。

[深浅底检查图](button-contours-check.png) 与切图清单由脚本同步生成。客户端类型检查和 Web 实际点击检查通过，微信导出及包体检查通过；未进行微信真机验证或正式发布。
