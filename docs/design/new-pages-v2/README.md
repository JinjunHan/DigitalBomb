## 设计约束与核对

- 正式多档首次默认四位。好友房稿演示“上次选择三位”，并明确“首次默认 4 位”。
- 选档图的卡片数量、组合数分别为 2/100、3/1,000、4/10,000。
- 互动教学只强调改动的第一列，不把历史反馈画成正确位置提示。
- 排除例子：0000→0、1234→2、9234→1。第一位确定为 1，其他三位排除 0；与全部反馈一致的候选共 192 种。其余位置仍需推理，不能将位置候选任意组合。
- 排除初稿曾出现历史反馈下的装饰圆点，已通过 imagegen 定向修订删除；只保留最终版，原始生成路径与修订提示词记在 prompts.json。
- 自由练习无对手、无倒计时、不计战绩。局内笔记保留剩余秒数，明确查看不暂停计时。
- 全部设计保持上方尤其右上方安全留白；正式落地仍须按微信胶囊实际安全区校准。

## 切图分层

背景书房与牌桌、木质标题牌、纸张与皮革面板、选项按钮、默认/上次选择角标、勾选态、数字卡牌、页签、主次按钮分别拆层。名字、数字、计时、记录、提示和选中状态应为运行时内容，不能将这些示例永久烘焙进正式对局。

概念原稿保存在 docs/design 下；运行素材独立保存于 assets/resources/art/learning-v2/。客户端以动态数据绘制数字、计时、记录与选择态。已接入的版本仍需微信开发者工具及真机验证，本地导出不代表正式发布。
