# 正式对局多档位与习惯记忆

## 产品规则

正式在线匹配、好友房创建均支持：2 位轻松局、3 位标准局、4 位挑战局。首次进入默认选中 **4 位**。所有档位仍允许重复和前导零，60 秒一次行动、最多 30 大轮，沿用公平补猜及超时规则。

点击在线匹配或创建房间后选择位数，确认才提交；已玩过的用户预选该入口上次确认的位数。偏好以 `digit-count-v1:<用户 ID>:public|friend` 存储在本机，两个入口互不覆盖；不同账号隔离。取消改选、练习、教学、加入他人的房间均不写偏好。不提供跨设备同步承诺；清理本机存储后回到四位。

## 服务端与协议

- `queue` / `create` 增加 `digitCount` 参数，只接受数字 2、3、4；省略为 4，兼容原请求。显式非法参数先拒绝，不清除已有队列或房间。
- 匹配票据保存位数，快照返回 `queuedDigitCount`。只配同档真人，保留本档等待顺序；没有同档对手时按原兜底期限创建同档机器人。重连不重新选择位数或兜底期限。
- 房间复制开局规则并固定 `digitCount`，快照直接返回。加入方按房主规则，不能用加入请求覆盖；输入和判定均依据服务器房间位数。
- 锁底牌、猜测、破解和最后补猜均使用本局长度。机器人按本局长度生成谜底并枚举候选，不读取对手底牌。
- 好友房返回流程保留位数、口令和先后手交换约定。房间口令独立于密码长度，始终四位。

## 客户端与素材

复用现有空白纸张、按钮、卡牌和记录条素材；新增选择面板及短位数确认面板，无新增位图资源。2/3 位分别展示对应数量的底牌、输入卡、对手牌背和结算卡；原四位对战结构保留。对手牌背使用现有四牌图中完整最右侧牌的 SpriteFrame 子区域，不拉伸四张牌伪装成两张。

准备标题、对局标识、命中分母、记录、推理候选和成功反馈遵循本局位数。2/3 位全部命中使用完整命中提示，不再使用“还差几位”的四位语义。好友等待页与匹配页明确标注档位。
