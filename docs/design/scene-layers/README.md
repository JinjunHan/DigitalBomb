# 共用书房的 2.5D 分层场景

首页、好友入口/好友房、在线匹配、准备/游戏/结算共用一组场景素材。个人资料及普通弹窗沿用所属页面的视角。UI 保持屏幕坐标，不跟随场景透视变化。

## 素材

以既有 `assets/resources/art/lobby/background.png` 为参考，用内置 image_gen 制作四个独立图层；完整提示词在 `prompts.json`。sips 仅归一化输出尺寸，透明通道保留。

| 资源（assets/resources/art/scene/） | 内容 | 尺寸 |
| --- | --- | --- |
| room.png | 窗户、书架、猫、空椅子和补齐的地板 | 864×1536 |
| table.png | 无道具的完整桌面、木框和桌沿，上方透明 | 864×1536 |
| near-left.png | 茶杯与前景绿植，透明背景 | 512×1024 |
| near-right.png | 灯与笔记本，透明背景 | 512×1024 |

这是分层插画模拟的轻微镜头变化，不是可自由旋转的三维房间。房间与桌面覆盖整个竖屏；左右道具保持宽高比，位于 UI 下方，不接收输入。

## 运行时

`SceneBackdrop` 是与 Interface 平级、位于其下方的常驻节点，不参与 GameApp.render 的销毁重建。四张素材全部就绪后再整体显示；未加载完或失败时保留原有大厅整图。运行时不再加载旧游戏背景。

`shared/scene-camera.ts` 管理四个视角：大厅基准、好友房拉远、匹配轻推近、游戏进一步推近并调整桌沿高度。切换用 0.9 秒 smoothstep 插值；远景移动幅度为桌面的 0.25 倍，前景纵向为 1.5 倍、横向为 1.6 倍。重复刷新不重启动画，中途反向从当前位姿继续，关闭界面动效直接到终点。静止时不重复更新节点变换。

## 验证

- 客户端类型检查通过；镜头与个人资料转场的 6 项测试通过，覆盖重绘不中断、快速反向、关闭动效、长帧限幅和边缘覆盖。
- 浏览器检查大厅、创建/关闭好友房、匹配、游戏视角；记录了真实截图帧，`docs/verification/scene-parallax.gif` 为按捕获时间编码的过渡演示。
- Web 和微信小游戏构建通过。微信真机性能与不同设备安全区尚未实测。
- 生成的场景图约增加 4.3 MB 资源；保留旧素材作为回退及既有资源，不在本次删除。
