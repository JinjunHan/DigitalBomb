## 本轮推进与后续顺序

1. 已修复：按真实美术高度定位底部轻提示，避免较高的确认超时图超出底部安全区。
2. 已补充 Web 夹具：双方命中 0～4 位、玩家离开/双方掉线、轮数上限/断线/认输/补猜超时结果，以及短屏提示边界。只验证界面分支，不代表真实服务器双人流程。
3. 优先后续：微信资料按钮从占位转为可用流程，先核实当前小游戏 API 及账号权限，覆盖同意、拒绝、失败和默认资料兜底。
4. 然后：微信分享邀请/入房链路，以及微信原生隐私授权等平台流程核查；这些不能仅通过游戏画面截图判定完成。
5. 最后：微信双机矩阵（匹配、口令、准备、补猜、超时、重连、再战），并确认音频、振动、安全区和后台恢复。

本轮没有接入新的微信授权 API，也没有发布线上版本。
